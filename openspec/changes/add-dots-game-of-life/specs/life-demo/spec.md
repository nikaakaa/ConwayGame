## Purpose

定义笔试演示的黑白棋盘、预置摆放工具、键盘与鼠标操作及文档交付，使查看者能够叠加摆放图案并逐代观察生命游戏。图案周期由统一规则自然产生，操作说明由文档提供，画面只保留黑底与白色活细胞。

## ADDED Requirements

### Requirement: 只显示黑白棋盘

演示画面 MUST 只显示纯黑背景与纯白活细胞，不能显示按钮、面板、文字、字体、悬停框或操作提示。首次进入演示 MUST 显示暂停的 Block 第零代，默认速度为每秒十代，默认观察范围为原点中心的每边 128 格。

#### Scenario: 进入演示

- **WHEN** 查看者打开演示场景并进入运行模式
- **THEN** 黑色棋盘上显示 Block 的白色活细胞，世界处于第零代暂停状态，画面没有文字或其他界面控件

#### Scenario: 操作不添加界面元素

- **WHEN** 用户选择工具、摆放、擦除或控制演化
- **THEN** 画面始终只显示黑底白色细胞，不出现状态文字、悬停框或操作提示

### Requirement: 提供稳定与震荡图案

演示 MUST 提供 Block、Beehive 两种稳定图案和 Blinker、Toad 两种二周期震荡图案。图案名称、类别和已知周期由预置目录与交付文档说明，不显示在演示画面中。

#### Scenario: 稳定图案保持不变

- **WHEN** 加载 Block 或 Beehive 并推进任意有限代数
- **THEN** 存活坐标集合保持不变

#### Scenario: 二周期图案恢复原状

- **WHEN** 加载 Blinker 或 Toad 并推进两代
- **THEN** 存活坐标集合恢复初始状态，第一代与初始状态不同

### Requirement: 覆盖移动与较长周期震荡

演示 MUST 提供 Glider、Lightweight Spaceship 两种周期移动图案，以及 Pulsar、Pentadecathlon 两种原地震荡图案，其最小周期分别为三和十五。文档 MUST 说明移动图案与原地震荡的区别，并注明这些预置图案覆盖题目中“循环震荡”表述的不同理解。

#### Scenario: 移动图案完成一个周期

- **WHEN** 加载 Glider 或 Lightweight Spaceship 并推进四代
- **THEN** Glider 的形状恢复并沿自身方向平移一个对角格，Lightweight Spaceship 的形状恢复并沿自身方向水平平移两个格子

#### Scenario: 较长周期图案恢复原状

- **WHEN** 从初始状态分别推进 Pulsar 三代和 Pentadecathlon 十五代
- **THEN** 两个图案分别恢复初始存活坐标集合，且各自没有更短的正整数周期

### Requirement: 摆放工具选择与原点重置

结构库首次使用 MUST 包含 Block、Beehive、Blinker、Toad、Glider、Lightweight Spaceship、Pulsar 和 Pentadecathlon，库中结构一视同仁，可改名和删除；用户从结构库选择摆放工具，初始工具为库中第一个结构。选择工具 MUST 只影响后续摆放与重置，不能改变现有世界、代数、运行状态或观察窗口。按 R MUST 清空世界并在原点加载当前工具预置的第零代，进入暂停状态并恢复原点中心与默认缩放；当前工具保持不变。

#### Scenario: 运行中选择另一个工具

- **WHEN** 世界已经演化若干代，用户从结构库选择另一个结构
- **THEN** 已有细胞、代数、观察窗口与运行状态不变，之后左键摆放和 R 重置使用新工具

#### Scenario: 在原点重置当前工具

- **WHEN** 用户在已有多个图案的世界中按 R
- **THEN** 原有细胞全部移除，原点只保留当前工具的预置初始坐标，代数为零且暂停，观察窗口恢复默认状态，工具选择保持不变

### Requirement: 运行与单步控制

Space MUST 开始或暂停自动演化，N MUST 先暂停再恰好推进一代。上下方向键 MUST 每次把速度增加或减少每秒一代，限制在每秒一至三十代，默认每秒十代。调速 MUST 保留现有坐标、代数和运行状态。系统 MUST 按操作到达顺序处理控制指令，不因同一帧收到多次单步而丢失操作。

#### Scenario: 切换自动演化

- **WHEN** 用户在暂停状态按 Space，之后再次按 Space
- **THEN** 世界先按当前速度自动演化，再停止自动演化并保留已有结果

#### Scenario: 暂停后单步推进

- **WHEN** 用户在暂停状态下按一次 N
- **THEN** 代数增加一，显示更新为完整下一代结果，系统保持暂停

#### Scenario: 运行中单步推进

- **WHEN** 用户在自动演化期间按 N
- **THEN** 系统切换为暂停，完成一次单步操作，之后不再自动推进

#### Scenario: 同一帧连续单步

- **WHEN** 用户在同一帧发出两次单步操作
- **THEN** 系统分别处理两次操作，代数总计增加二，并保持暂停

#### Scenario: 重置后紧接单步

- **WHEN** 用户依次发出 R 重置和 N 单步操作
- **THEN** 系统先恢复当前图案第零代，再推进到第一代，并保持暂停

#### Scenario: 调整运行速度

- **WHEN** 用户按上下方向键修改每秒推进代数
- **THEN** 后续自动演化使用新的时间间隔，不重置已有世界状态

#### Scenario: 调速到达边界

- **WHEN** 速度已经为每秒三十代时再次按上方向键，或已经为每秒一代时再次按下方向键
- **THEN** 速度保持在对应边界

### Requirement: 鼠标叠加摆放与连续擦除

左键每次在棋盘内按下 MUST 以鼠标世界坐标为锚点，将当前工具的全部预置坐标叠加到已有世界，不清除其他细胞，也不沿左键拖动路径重复摆放。重叠坐标 MUST 保持唯一。右键点按或拖动 MUST 将经过的单个格子设为死亡，拖动轨迹 MUST 补齐相邻采样点间的格子。摆放和擦除 MUST 自动暂停并保留代数，释放鼠标后仍然暂停。棋盘外操作 MUST 不编辑细胞。

#### Scenario: 向已有世界叠加图案

- **WHEN** 用户选择 Glider 工具并在棋盘内左键点按
- **THEN** 当前工具的五个相对坐标以鼠标世界坐标为锚点加入世界，已有细胞保留，世界暂停且代数不变

#### Scenario: 重叠摆放不会翻转

- **WHEN** 用户在同一坐标连续摆放同一预置
- **THEN** 重叠格子仍然存活，存活坐标没有重复项

#### Scenario: 摆放后单步

- **WHEN** 用户左键摆放预置后按 N
- **THEN** 新增坐标先与已有世界合并，再共同按规则推进一代

#### Scenario: 连续擦除

- **WHEN** 右键拖动的相邻两次采样跨过多个格子
- **THEN** 两点之间的格子按整数线段连续擦除，重复经过死亡格子仍然保持死亡

#### Scenario: 擦除轨迹离开棋盘

- **WHEN** 用户右键拖动离开棋盘后重新进入
- **THEN** 擦除从重新进入的格子继续，不连接离开期间的轨迹

#### Scenario: 运行中开始编辑

- **WHEN** 自动演化期间用户在棋盘内左键摆放或右键擦除
- **THEN** 世界暂停并应用编辑，编辑不增加代数，释放鼠标后仍然暂停

### Requirement: 清空保留工具与视野

按 C MUST 移除全部活细胞、暂停并将代数归零，同时保留当前摆放工具、观察窗口位置和缩放。

#### Scenario: 清空后重新摆放

- **WHEN** 用户选择某个工具、移动视野后按 C，再在棋盘内左键点按
- **THEN** 视野与工具选择保持不变，世界只包含新摆放的预置坐标，代数为零且暂停

### Requirement: 观察窗口独立于世界

演示 MUST 支持中键拖动平移、滚轮分档缩放和 Home 复位视野。可见范围 MUST 为每边 32、64、128 或 256 格，默认 128 格。滚轮缩放 MUST 保持鼠标下的世界格子不变；Home MUST 恢复原点中心和默认缩放。观察操作 MUST 只改变显示，不修改细胞、代数、摆放工具或运行状态。高频显示更新 MUST 复用像素缓冲区。

#### Scenario: 平移查看世界

- **WHEN** 用户在暂停状态下平移窗口
- **THEN** 显示内容对应新的世界坐标范围，当前代数和活细胞数量保持不变

#### Scenario: 缩放后仍能准确摆放

- **WHEN** 用户在棋盘内滚轮缩放后点按一个格子
- **THEN** 缩放前后鼠标指向同一个世界格子，预置以该坐标为锚点摆放，负坐标区域遵循相同规则

#### Scenario: 运行中平移与缩放

- **WHEN** 用户在自动演化期间中键拖动或滚轮缩放
- **THEN** 世界继续演化，操作只改变观察范围

#### Scenario: 回到原点

- **WHEN** 用户移动或缩放窗口后按 Home
- **THEN** 窗口恢复原点中心与默认缩放，世界状态、代数、工具选择和运行状态不变

### Requirement: 提供可运行入口和交付文档

项目 MUST 提供明确的演示场景入口、README 和技术说明。文档 MUST 说明 Unity 版本、结构库与初始结构、键盘与鼠标操作、叠加摆放与重置规则、图案、无预设边界的含义、DOTS 的实际使用范围、模块职责、效率取舍和已执行检查的范围。

#### Scenario: 查看笔试交付

- **WHEN** 查看者按 README 打开指定演示场景并运行
- **THEN** 可以按文档选择预置工具、叠加摆放并控制演化，技术说明能够对应到实际实现；未执行的性能或运行检查被明确标记，不提供虚构的测量结论
