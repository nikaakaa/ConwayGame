# ConwayGame · Conway's Game of Life

基于 Unity 6 的康威生命游戏，支持自由绘制、结构盖章、框选编辑、世界存档和大型地图。黑白棋盘铺满窗口，可平移、缩放观察。离屏区域保留相同的演化语义，移动视野或导出时按代数快照计算。

演化核心使用 Entities 调度、Burst 位图计算与 HashLife 共享四叉树，支持跨代缓存、分帧推进和节点回收。结构可通过 RLE、Plaintext 和 JSON 导入，RLE 可与其他生命游戏工具交换。

## 生命游戏规则

每个格子只有存活和死亡两种状态，以周围八格为邻居。整个世界使用 B3/S23 规则同步演化：

- 死亡格有恰好三个活邻居时出生。
- 存活格有两个或三个活邻居时继续存活。
- 其他格子在下一代死亡。

世界按需扩展，没有固定棋盘边界或边缘环绕，实际规模受坐标类型、内存和算力限制。

## 启动

安装 Git，然后克隆工程：

```bash
git clone https://github.com/nikaakaa/ConwayGame.git
```

工程与全部 16 张地图通过普通 Git 保存。最大地图 `metaglider-0e0p.rle.gz` 约 75.7 MB，使用 gzip 完整无损压缩，由游戏载入时自动解压；地图预览与工程配置随仓库提供。

1. 使用 Unity **6000.3.3f1** 打开工程，等待包解析与编译完成。
2. 打开 `Assets/GameOfLife/Scenes/GameOfLife.unity`，进入 Play。
3. 在开始界面选择“新世界”，进入第零代、暂停的空棋盘。首次运行默认速度每秒 10 代，当前工具为单格笔刷；从已有世界新建时保留当前速度和工具。

第一次体验可按 `L` 打开结构库，选择 `Glider` 后按回车，左键放置，再按 `Space` 开始演化。已有演示场景无需重新生成。

主要依赖：Entities 1.4.8、Burst 1.8.29、Collections 2.6.8、Mathematics 1.3.3、Input System 1.17.0、URP 17.3.0 和 UGUI 2.0.0。菜单与工具栏使用 UI Toolkit。

构建场景列表已将 `GameOfLife.unity` 设为首个场景。需要独立程序时，在 Unity 的 Build Profiles 中选择目标平台后构建，产物可放在已忽略的 `Builds/` 目录。

## 操作

| 输入 | 行为 |
| --- | --- |
| 0 / S | 单格笔刷 / 框选工具 |
| L | 打开结构库 |
| 左键按住、拖动 | 连续画单格，或以鼠标世界格子为锚点连续盖章所选结构；自动暂停、保留代数。框选工具下拖出矩形选区，单击取消选区 |
| 右键点击或拖动 | 擦除经过的单格，自动暂停、保留代数；拖动连续补点 |
| 中键拖动 | 平移视野 |
| 滚轮 | 以鼠标格子为锚点缩放，长边每档扩大或缩小两倍，范围 8–67,108,864 格 |
| Space | 开始或暂停 |
| N | 暂停并推进一代 |
| C | 清空、暂停、代数归零，保留工具与视野 |
| R | 清空并在原点放置当前结构；暂停、代数归零，恢复默认视野 |
| Delete / Backspace | 删除选区内的活细胞，自动暂停 |
| Esc | 逐层退出：收起二级图标、取消选区、退出盖章（包括 Ctrl+V 导入后的盖章）回到之前的工具 |
| Ctrl+C | 把选区（无选区时为整个棋盘）以 RLE 复制到剪贴板 |
| Ctrl+V | 从剪贴板导入 RLE、Plaintext 或 JSON 结构，存入结构库并设为盖章笔刷 |
| Home | 只将视野恢复到原点中心、长边 128 格 |
| ↑ / ↓ | 目标速度翻倍或减半，范围每秒 1–1,073,741,824 代；按住每 0.12 秒重复 |
| Tab | 收起或展开图标，收起后只留滑翔机 |
| ? | 显示全部快捷键 |

拖动使用 Bresenham 补齐采样点之间的格子，结构盖章允许重叠，已有活细胞不会翻转。笔画离开棋盘后中断，重新进入时从新位置继续。平移和缩放不改变世界或运行状态。

单格与盖章笔刷下，鼠标所在位置显示灰色半透明预览，已有活细胞保持白色。选区以深灰底和黑白虚线框显示，松手后右下角浮出存入、复制、删除三个图标（拖动中不显示）；存入会打开结构库并直接进入改名。切换到其他笔刷时取消选区。

缩放档位表示窗口长边对应的格数，短边按屏幕比例显示。棋盘按 3.5 倍视野预加载周边，使用 3584² 前后台纹理，在一屏内保持 1024² 的纹素密度；预览使用独立 1024² 纹理。近处一格占多个像素，远处多个格子可合并显示为一个白色像素，世界数据保留逐格精度。连续多档缩小或远距离移动仍可能超出已完成缓存，详见[显示设计](Docs/路径/混合演化核心设计.md#按缩放显示)。

## 界面

所有图标都用与棋盘相同的方块绘制，只有暗灰与白两种状态，没有边框，每个形状只表示一种操作；文字只在鼠标悬停时出现，且从不出现在光标下方：主界面的提示显示在一级图标行右侧，选区操作条和结构库的提示显示在图标上方。界面以 1080 像素高为 1 倍，窗口更高时等比放大，小窗口不缩小。

左上角的滑翔机随代数切换相位，运行时全亮；悬停显示代数和最近一次完整快照的活细胞数，人口提示会标明快照代数。播放时不逐帧结算全图人口。点击滑翔机收起或展开其余图标，展开后有三组操作：

| 图标 | 二级 |
| --- | --- |
| 演化（时钟，运行时全亮） | 运行/暂停、单步、减速、速度（可滚轮调整）、加速 |
| 编辑（显示当前工具，盖章时为结构缩略图） | 画笔、框选、盖章（当前结构）、结构库 |
| 世界 | 清空、重置、保存、开始界面、帮助、退出程序 |

二级再点一次一级图标或按 Esc 收起，鼠标移开不收起。操作结果在滑翔机右侧短暂提示。保存先提示“保存中”，固定调用时的世界快照并分帧收集细胞，再在后台编码、写文件和生成缩略图，写完提示“已保存”。完成收集时仍需复制细胞数组，大世界仍有计算和内存成本。

## 开始界面、存档与地图

开始界面菜单为新世界、继续（有存档时）、存档、地图、退出程序；从编辑界面返回时最上方多一项“返回”，Esc 也可直接回到当前世界。鼠标或方向键加回车选择。

退出入口位于开始菜单底部和“世界”二级菜单的电源图标。需要保留当前棋盘时，请先保存并等待完成；退出不会自动保存。发行版关闭程序，Unity Editor 中停止 Play。

- 存档保存整个世界，写入 `Application.persistentDataPath/Saves`：同名的 `.rle`（世界，以 `#C life-anchor x,y` 记录左上角，载入后细胞回到原来的位置）、`.json`（名称）和 `.png`（缩略图），三者都在保存时于后台写好。存档列表与地图一样只读名称和缩略图，选中才解析世界。存档按保存时间从新到旧排列，“继续”载入最新一个。编辑中点菜单的保存：来自存档的世界覆盖该存档，新世界或地图新建存档。存档可以改名（只改名称文件）、两步删除。
- 地图是收录的大型结构，只读，选中后作为新世界放在原点。当前共 16 张，包含 Gunstar、P690 飞船工厂、Breeder 1、c/5 灰船、Primer、图灵机、空间填充器、**Life in Life：OTCA 银河（15×15）**，以及 Gemini、Caterpillar、Waterbear、Demonoid、Linear propagator、π 计算机、Hexadecimal 与 **0E0P 自构造宏滑翔机**。文件位于 `Assets/StreamingAssets/LifePatterns/`，[来源记录](Docs/参考/复杂结构来源.md)列出规模、行为、作者和下载地址。地图列表不读取地图文件：名称和缩略图来自离线生成的 `maps.json` 与同名 PNG，选中某个地图后才读取、解析并载入，期间显示“载入中”。新增或修改地图后运行 `python -I Tools/MapPreviews/generate_previews.py` 重新生成；缺少预览的地图显示文件名和统一图标。新增巨构未测解析与载入耗时。载入后视野默认是中心 128 格，用滚轮缩小查看全貌。运行中外部新增地图后，重新打开地图列表即可更新。
- 载入存档或地图都会替换当前世界，代数从零开始；存档暂不恢复代数。大型世界的编译必须在主线程完成，先显示“载入中”再开始，期间画面静止。

## 结构库

结构库是盖章用的小结构仓库，按 L 或从编辑二级的结构库图标打开。库中所有结构一视同仁，没有内置与自定义之分，存放在 `Application.persistentDataPath/Patterns`，每个 JSON、RLE 或 `.cells` 文件就是一个结构，按创建顺序排列。

- 存入：有选区时存入框内活细胞，否则存入整个棋盘；存入后直接进入改名，回车确认。
- 导入：从剪贴板读取 RLE、Plaintext 或 JSON，同名且位图相同的结构不重复保存。
- 删除：第一次点删除图标变白并提示，3 秒内再点才删除文件；库中至少保留一个结构。
- 改名：双击名称或按 F2，回车保存、Esc 取消；只改文件中的名称，位置不变。
- 搜索：点搜索图标或按 `/` 展开输入框，按名称过滤。
- 界面上方是图标栏，中间是会动的缩略图网格，底部一行状态栏显示名称（悬停的或选中的）和盖章、复制、删除；网格本身就是预览，不再另放大图。
- 方向键选择，回车或双击盖章：选中结构、关闭结构库并切换到盖章笔刷。
- Esc 或点击浮层外关闭。左上角的暗色标题区分结构、存档与地图，列表为空时显示“空”。

每次打开结构库会检查目录，外部放入的文件无需刷新；目录未变化时不重新解析。复制使用标准 RLE（`#N 名称`、`x = 宽, y = 高, rule = B3/S23` 和行程编码主体），可直接贴到 LifeWiki、Golly 等工具。导入识别 RLE（确认规则为 B3/S23，`b`/`.` 为死、`o` 为活、`$` 换行、`!` 结束）、Plaintext（`!Name:` 为名称，`.` 为死，`O` 或 `*` 为活）和本工程 JSON：

```json
{"name":"自定义结构","cells":[{"x":-1,"y":0},{"x":0,"y":0},{"x":1,"y":0}]}
```

结构坐标为相对摆放锚点的位置；存入时按活细胞包围盒中心转换，再次摆放不会带上原来的世界位置。

## 项目结构与调用链

| 路径 | 职责 |
| --- | --- |
| `Assets/GameOfLife/Runtime/` | 输入、演化、显示、结构库与存档 |
| `Assets/GameOfLife/Scenes/GameOfLife.unity` | 可直接运行的演示场景 |
| `Assets/GameOfLife/UI/` | UI Toolkit 样式与面板配置 |
| `Assets/GameOfLife/Editor/LifeSceneBuilder.cs` | `Tools/Game of Life/Create Demo Scene` 场景生成入口 |
| `Assets/StreamingAssets/LifePatterns/` | 16 张地图、缩略图、索引及上游许可 |
| `Tools/MapPreviews/` | 离线生成地图缩略图与索引 |
| `Tools/Benchmarks/` | 核心采样、交互回放工具与已有结果 |
| `Docs/` | 实现、设计、素材来源与性能记录 |

`LifeController` 接收鼠标、键盘和工具栏操作，将编辑动作写入 `LifeCommand` 缓冲区。`LifeSimulationSystem` 按顺序消费指令，调用唯一的 `LifeWorld` 修改棋盘、推进视野区域请求和处理导出。`LifeWorld.cs` 负责位图树与 HashLife，`LifeWorld.Regions.cs` 负责世界版本、代数快照和区域缓存。视野请求完成后发布区域结果和实际代数，`LifeView` 再通过 `LifeRasterJob` 绘制可见区域。棋盘使用一个 Entity，细胞存于共享树中。

`LifePatternStore` 管理可编辑的结构文件，`LifeWorldStore` 管理世界存档和只读地图。文件读取、解析与保存围绕这两个模块进行，演化过程不读取文件。

## 实现与限制

- 速度设置是目标代速，实际推进速度取决于图案、缓存命中和硬件。重复结构可以共享演化结果，混沌区域需要更多实际计算。
- 远景会合并显示多个格子，模拟仍保留逐格精度。连续多档缩小或远距离移动可能超出已经完成的显示缓存。
- 大型地图的读取、gzip 解压和解析在后台进行，编译成世界树仍在主线程执行。压缩地图解压后仍需处理完整 RLE 和地图数据，解析与建树仍有内存成本。保存、复制和存入结构按快照分帧计算，完成时仍有数组复制与编码成本，大世界可能出现停顿。
- 存档保留细胞位置与名称，载入后代数从零开始。
- 新增巨型地图未逐一验证完整演化周期，也未全部测量解析和载入耗时。
