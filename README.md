# Conway's Game of Life

Unity 6 生命游戏，使用 Entities 调度、Burst 位图内核与 HashLife 共享四叉树。黑白棋盘铺满 Game 视图，左上角提供可隐藏的小工具栏；离屏细胞继续演化。

核心已接入 16×16 位图叶子、子树盖章、跨代缓存、分帧推进与节点回收。连续画笔提交整段命令，显示按可见树和缩放查询，结构支持 JSON、RLE 与 Plaintext。实现与限制见[技术说明](Docs/GameOfLife.md)，实际采样见[性能记录](Docs/测试/生命游戏性能.md)。

## 启动

1. 使用 Unity **6000.3.3f1** 打开工程，等待包解析与编译完成。
2. 打开 `Assets/GameOfLife/Scenes/GameOfLife.unity`，进入 Play。
3. 初始棋盘为原点附近的 Block，第零代、暂停，默认速度每秒 10 代，当前工具为单格笔刷。

依赖：Entities 1.4.8、Burst 1.8.29、Collections 2.6.8、Mathematics 1.3.3，以及 UGUI、UI Toolkit 和 Input System 1.17.0。

## 操作

| 输入 | 行为 |
| --- | --- |
| 0 | 切换单格笔刷 |
| 数字 1–8 | 选择下表中的内置结构笔刷，保留当前世界 |
| S | 切换框选工具 |
| 左键按住、拖动 | 连续画单格，或以鼠标世界格子为锚点连续盖章所选结构；自动暂停、保留代数。框选工具下拖出矩形选区，单击取消选区 |
| 右键点击或拖动 | 擦除经过的单格，自动暂停、保留代数；拖动连续补点 |
| 中键拖动 | 平移视野 |
| 滚轮 | 以鼠标格子为锚点缩放，长边每档扩大或缩小两倍，范围 8–67,108,864 格 |
| Space | 开始或暂停 |
| N | 暂停并推进一代 |
| C | 清空、暂停、代数归零，保留工具与视野 |
| Delete / Backspace | 删除选区内的活细胞，自动暂停 |
| Esc | 取消选区 |
| Ctrl+C | 把选区（无选区时为整个棋盘）以 RLE 复制到剪贴板 |
| Ctrl+V | 从剪贴板导入 RLE、Plaintext 或 JSON 结构，并设为盖章笔刷 |
| R | 清空并在原点加载当前所选结构，支持自定义结构；暂停、代数归零，恢复默认视野 |
| Home | 只将视野恢复到原点中心、长边 128 格 |
| ↑ / ↓ | 目标速度翻倍或减半，范围每秒 1–1,073,741,824 代；按住每 0.12 秒重复 |
| Tab | 显示或隐藏工具栏 |

拖动使用 Bresenham 补齐采样点之间的格子，结构盖章允许重叠，已有活细胞不会翻转。笔画离开棋盘后中断，重新进入时从新位置继续。平移和缩放不改变世界或运行状态。

单格与盖章笔刷下，鼠标所在位置显示灰色半透明预览，已有活细胞保持白色。选区以深灰底和黑白虚线框显示；切换到其他笔刷时取消选区。

工具栏头部显示随代数变换相位的滑翔机、代数和活细胞数；下方可选择单格、盖章或框选，控制运行、单步、清空和重置，调整缩放与速度，并提供保存、刷新、目录、复制、导入和删除。按钮不取键盘焦点，Space 等快捷键始终交给棋盘。复制、导入、保存的结果在工具栏下方短暂提示。速度既可直接输入，也可用倍速按钮调整。名称或速度输入框聚焦时，键盘快捷键暂停处理，移开焦点后恢复。

缩放档位表示窗口长边对应的格数，短边按屏幕比例显示。显示使用固定 `1024 × 1024` 纹理：近处一格占多个像素，远处多个格子可合并显示为一个白色像素，世界数据仍然保留每个格子的精度。

## 保存和添加结构

在工具栏输入结构名称并点击保存：有选区时只保存框内活细胞，否则保存整个已公布棋盘（包括屏幕外的活细胞），写入 `Application.persistentDataPath/Patterns`。空棋盘或空选区不能保存。保存后，新结构立即出现在结构列表中并成为当前笔刷；每次保存创建新的 GUID 文件，同名也不覆盖旧结构。

点击打开目录查看实际保存位置。以后可把以下格式的 UTF-8 JSON 文件放进该目录，再点击刷新，与八种内置结构一起使用：

```json
{"name":"自定义结构","cells":[{"x":-1,"y":0},{"x":0,"y":0},{"x":1,"y":0}]}
```

### 剪贴板导入导出

复制使用标准 RLE（`#N 名称`、`x = 宽, y = 高, rule = B3/S23` 和行程编码主体），可直接贴到 LifeWiki、Golly 等工具。导入识别三种文本：

- RLE：读取 `#N` 作为名称，确认规则为 B3/S23，游程直接写位图；`b`/`.` 为死、`o` 为活、`$` 换行、`!` 结束；
- Plaintext（`.cells`）：`!Name:` 为名称，`.` 为死，`O` 或 `*` 为活；
- 本工程 JSON。

导入的结构保存为目录中的 RLE 文件并出现在结构列表；同名且位图集合相同的结构不会重复保存。格式失败时提示具体原因，保留当前笔刷。目录也可直接放入 `.rle` 或 `.cells` 文件后刷新。

坐标表示相对摆放锚点的位置。通过工具栏保存时，程序按活细胞包围盒中心转为相对坐标，因此保存结构再次摆放时不会带上原来的世界位置。

## 预置图案

| 数字 | 图案 | 类别 | 周期 | 一个周期后的位移 |
| --- | --- | --- | --- | --- |
| 1 | Block | 稳定 | 1 | 原地 |
| 2 | Beehive | 稳定 | 1 | 原地 |
| 3 | Blinker | 震荡 | 2 | 原地 |
| 4 | Toad | 震荡 | 2 | 原地 |
| 5 | Glider | 飞船 | 4 | 向右、向下各 1 格 |
| 6 | Lightweight Spaceship | 飞船 | 4 | 向左 2 格 |
| 7 | Pulsar | 震荡 | 3 | 原地 |
| 8 | Pentadecathlon | 震荡 | 15 | 原地 |

全部使用 B3/S23 规则自然演化。题目中“循环震荡”的表述同时用两种移动飞船和两种较长周期原地震荡覆盖。叠加图案可能相互作用，此表只描述各预置独立存在时的周期。

内置图案统一维护在 `Assets/GameOfLife/Runtime/LifePatterns.cs`，自定义结构统一由 `LifePatternStore` 读写。技术分析与成本见 [实现说明](Docs/GameOfLife.md)。
