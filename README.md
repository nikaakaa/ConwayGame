# Conway's Game of Life

Unity 6 生命游戏，使用 Entities、Jobs、Burst 和稀疏整数坐标。黑白棋盘铺满 Game 视图，左上角提供可隐藏的小工具栏；离屏细胞继续演化。

当前核心仍逐代计算活细胞及其邻域。后续采用统一四叉树、位图叶子和 HashLife 演化缓存，兼顾连续编辑、混沌图案与重复电路，并以真实 Life-in-Life 图案作为大规模目标。该方案尚未实施，见[混合演化核心设计](Docs/路径/混合演化核心设计.md)。

## 启动

1. 使用 Unity **6000.3.3f1** 打开工程，等待包解析与编译完成。
2. 打开 `Assets/GameOfLife/Scenes/GameOfLife.unity`，进入 Play。
3. 初始棋盘为原点附近的 Block，第零代、暂停，默认速度每秒 10 代，当前工具为单格笔刷。

依赖：Entities 1.4.8、Burst 1.8.29、Collections 2.6.8、Mathematics 1.3.3，以及 UGUI、UI Toolkit 和 Input System 1.17.0。

## 操作

| 输入 | 行为 |
| --- | --- |
| 0 | 切换单格笔刷 |
| 数字 1–8 | 选择下表中的内置结构笔刷，保留当前世界 |
| 左键按住、拖动 | 连续画单格，或以鼠标世界格子为锚点连续盖章所选结构；自动暂停、保留代数 |
| 右键点击或拖动 | 擦除经过的单格，自动暂停、保留代数；拖动连续补点 |
| 中键拖动 | 平移视野 |
| 滚轮 | 以鼠标格子为锚点缩放，长边每档扩大或缩小两倍，范围 8–16384 格 |
| Space | 开始或暂停 |
| N | 暂停并推进一代 |
| C | 清空、暂停、代数归零，保留工具与视野 |
| R | 清空并在原点加载当前所选结构，支持自定义结构；暂停、代数归零，恢复默认视野 |
| Home | 只将视野恢复到原点中心、长边 128 格 |
| ↑ / ↓ | 速度翻倍或减半，范围每秒 1–1000 代；按住每 0.12 秒重复 |
| Tab | 显示或隐藏工具栏 |

拖动使用 Bresenham 补齐采样点之间的格子，结构盖章允许重叠，已有活细胞不会翻转。笔画离开棋盘后中断，重新进入时从新位置继续。平移和缩放不改变世界或运行状态。

工具栏可选择单格或结构，控制运行、单步、清空和重置，调整缩放与速度。速度既可直接输入，也可用倍速按钮调整。名称或速度输入框聚焦时，键盘快捷键暂停处理，移开焦点后恢复。

缩放档位表示窗口长边对应的格数，短边按屏幕比例显示。显示使用固定 `1024 × 1024` 纹理：近处一格占多个像素，远处多个格子可合并显示为一个白色像素，世界数据仍然保留每个格子的精度。

## 保存和添加结构

在工具栏输入结构名称并点击保存，将整个已公布棋盘保存到 `Application.persistentDataPath/Patterns`，包括屏幕外的活细胞。空棋盘不能保存。保存后，新结构立即出现在结构列表中并成为当前笔刷；每次保存创建新的 GUID 文件，同名也不覆盖旧结构。

点击打开目录查看实际保存位置。以后可把以下格式的 UTF-8 JSON 文件放进该目录，再点击刷新，与八种内置结构一起使用：

```json
{"name":"自定义结构","cells":[{"x":-1,"y":0},{"x":0,"y":0},{"x":1,"y":0}]}
```

坐标表示相对摆放锚点的位置。通过工具栏保存时，程序按活细胞包围盒中心转为相对坐标，因此保存结构再次摆放时不会带上原来的世界位置。

## 预置图案

| 数字 | 图案 | 类别 | 周期 | 一个周期后的位移 |
| --- | --- | --- | --- | --- |
| 1 | Block | 稳定 | 1 | 原地 |
| 2 | Beehive | 稳定 | 1 | 原地 |
| 3 | Blinker | 震荡 | 2 | 原地 |
| 4 | Toad | 震荡 | 2 | 原地 |
| 5 | Glider | 飞船 | 4 | 向右、向下各 1 格 |
| 6 | Lightweight Spaceship | 飞船 | 4 | 向左 2 格 |
| 7 | Pulsar | 震荡 | 3 | 原地 |
| 8 | Pentadecathlon | 震荡 | 15 | 原地 |

全部使用 B3/S23 规则自然演化。题目中“循环震荡”的表述同时用两种移动飞船和两种较长周期原地震荡覆盖。叠加图案可能相互作用，此表只描述各预置独立存在时的周期。

内置图案统一维护在 `Assets/GameOfLife/Runtime/LifePatterns.cs`，自定义结构统一由 `LifePatternStore` 读写。技术分析与成本见 [实现说明](Docs/GameOfLife.md)。
