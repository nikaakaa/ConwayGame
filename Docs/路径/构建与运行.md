# 构建与运行 Windows 版本

## 运行现成程序

当前 ZIP 已重新构建，包含主菜单/游戏双场景、完整 `.rle.gz` 地图加载和最大巨构的加载、区域查询、冷启动步长修复。程序源码提交为 `b174a4f`，构建目标为 Windows x64、Mono、非 Development Build。

解压 `Builds/GameOfLife-Windows-x64.zip`，运行解压目录中的 `GameOfLife.exe`。本机未压缩的程序位于 `Builds/Windows-Giant/GameOfLife.exe`。

保留 EXE 同目录的 `GameOfLife_Data`、`MonoBleedingEdge`、`D3D12`、`UnityPlayer.dll` 和其他附带文件。分发使用完整 ZIP。`*_BurstDebugInformation_DoNotShip` 是构建调试资料，未放入 ZIP。

程序先进入主菜单。选择“新世界”进入空棋盘，选择“地图”载入复杂结构，也可载入存档；游戏内可返回主菜单。程序包带有 `运行说明.txt`，完整操作见 [README](../../README.md#操作)。最大的 0E0P 地图仍有一分钟以上的首次解析和较慢的冷演化，当前实测范围及限制见[性能记录](../测试/生命游戏性能.md#最大巨构的加载与首次推进)。

存档和盖章结构保存在 `Application.persistentDataPath` 下的 `Saves` 与 `Patterns`，不写入程序目录。本机对应 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/麦吉太文笔试/`。这些用户数据不随源码提交或发行包分发，重载存档后代数从零开始。

## 从项目构建

使用 Unity **6000.3.3f1**，安装 Windows Build Support。当前产物为 `StandaloneWindows64`、Mono 后端、非 Development Build，Burst 原生库随程序打包。

以下步骤使用本机已安装的 Unity CLI。目标 Editor 需要启动项目中的 Pipeline 服务，`unity` 命令需要能在终端找到。

1. 在 Unity 打开目标工程。需要保留当前棋盘时，先在世界菜单保存存档。
2. 退出 Play，等待资源导入和编译结束。
3. 在项目根目录执行下列 PowerShell 命令。Python 将数组参数编码为 JSON，避免终端改写引号。

```powershell
@'
import json
import subprocess
from pathlib import Path

project = Path.cwd()
subprocess.run([
    "unity", "--json", "command", "--project-path", str(project),
    "build", "StandaloneWindows64",
    str(project / "Builds/Windows-Giant/GameOfLife.exe"), "",
    json.dumps(["DetailedBuildReport"]),
    json.dumps([
        "Assets/GameOfLife/Scenes/MainMenu.unity",
        "Assets/GameOfLife/Scenes/GameOfLife.unity"
    ]),
    "true", "false"
], check=True)
'@ | python -
```

4. 构建提交返回 `queued` 后，执行下列命令读取原构建状态。等待 `status` 为 `completed`，核对 `result` 为 `Succeeded`、`totalErrors` 为 `0`，再分发产物。

```powershell
unity --json command --project-path "$PWD" build_status
```

构建按顺序包含 `Assets/GameOfLife/Scenes/MainMenu.unity` 和 `Assets/GameOfLife/Scenes/GameOfLife.unity`，启动时先进入主菜单，不带模板 SampleScene。`Tools/Game of Life/Create Demo Scenes` 会重新生成这两个场景并重写构建列表。输出在 Git 忽略的 `Builds/` 内，源码提交不包含可执行文件。命令生成 Windows 目录；ZIP 是构建完成后对该目录的分发打包。
