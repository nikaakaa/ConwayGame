## 来源与许可

采用固定提交下载，避免上游更新后同一个 URL 指向不同内容。这里区分上游分发包的许可和图案的发现者，不把仓库维护者写成图案作者，也不将公开下载等同于公有领域。

`gunstar.rle`、`breeder1.rle`、`c5greyship.rle`、`primer.rle`、`turingmachine.rle` 来自 [copy/life](https://github.com/copy/life/tree/924c90afb529ad5d417f11d795bc1b400fff8d18)，提交 `924c90afb529ad5d417f11d795bc1b400fff8d18`。该分发仓库附带 [BSD 2-Clause 许可](https://github.com/copy/life/blob/924c90afb529ad5d417f11d795bc1b400fff8d18/LICENSE)，原文随素材保存在 `COPY-LIFE-LICENSE.txt`。其 README 同时说明示例的更早来源为 ConwayLife 的图案集合；RLE 中的作者、LifeWiki 条目链接和其他原注释均保留。上述许可是仓库的分发声明，文件没有另列作者个人许可，不据此宣称其发现者放弃著作权。

`p690-cordership-gun.rle`、`spacefiller.rle` 与 OTCA 银河来自 [Golly 项目](https://sourceforge.net/p/golly/code/ci/dcbc08738f07532dc8dbbf74d83b9d52a29a6953/tree/)，所用下载镜像为 [AlephAlpha/golly](https://github.com/AlephAlpha/golly/tree/dcbc08738f07532dc8dbbf74d83b9d52a29a6953)，固定提交 `dcbc08738f07532dc8dbbf74d83b9d52a29a6953`。上游 [License.html](https://github.com/AlephAlpha/golly/blob/dcbc08738f07532dc8dbbf74d83b9d52a29a6953/docs/License.html) 声明 GPL-2.0-or-later，原件随素材保存在 `GOLLY-LICENSE.html`。这三份图案没有独立的许可标头，本包按其所属分发项目保留许可、作者和可编辑的 RLE 源数据；这些来源声明针对第三方素材，没有把本工程的自研 C# 代码重新许可。
