## 输入与实际结果

从 `MainMenu.unity` 进入 Play，临时启用后台运行，让 Editor 未获焦点时仍执行生命周期；结束恢复原值并退出 Play。新世界使用正式会话与场景切换入口，“继续”使用主菜单保存的实际操作回调。绘制由 `EventSystem.RaycastAll` 命中结果交给 `ExecuteEvents` 的按下、抬起处理，再等待正式 System 消费指令。

| 阶段 | 实际结果 |
| --- | --- |
| 首次进入游戏并画一格 | 射线只命中 `Board`，输入的 Point、Click 动作启用，正式棋盘人口为 1 |
| 平移后回主菜单 | 控制器、LifeView、工具栏和三张棋盘纹理均为 0；EventSystem 为 1；菜单提供新世界、继续、存档、地图、退出程序 |
| 通过继续再次进入 | 创建了新的控制器；世界会话保留，人口仍为 1，视野仍为原点 `(-48,-56)`、边长 128 格 |
| 再画另一格 | 射线仍只命中 `Board`，Point、Click 仍启用；命令消费后人口为 2，命令队列为 0 |
| 第二次进入的对象数量 | 控制器、LifeView、工具栏、UIDocument、EventSystem 各 1；棋盘纹理为 3 |

## 已修复的问题与边界

生成第二个 EventSystem 时，`AssignDefaultActions` 曾复用前一个模块卸载后失效的默认动作引用，生成器因此中断。现在先在未启用对象上绑定项目持久化 Input Actions 及 UI 引用，再启用模块。生成器跨 `NewSceneMode.Single` 保存的 `PanelSettings` 引用也曾成为空引用；现在在目标场景创建后取得资源，已核对两个场景保存后的实际引用。
