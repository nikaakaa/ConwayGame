# 生命游戏核心性能记录

## 条件与可用结论

2026-10-17，Unity 6000.3.3f1，Entities 1.4.8、Burst 1.8.29、Collections 2.6.8；i9-13900HX，24 核、32 线程。采样前整机 CPU 负载约 54%，另有项目与 Editor 负载。以下是目标 Editor 内生产核心的绝对测量；旧核心未获得有效同输入基线，不报告加速倍数。

通过官方 Unity CLI 的 `eval_file` 创建独立 World，调用正式 `LifeWorld`、`LifeSimulationSystem` 与 `LifeRasterJob`。Stopwatch 只包住实际操作，CLI 分发、动态编译、图案生成、解析与初始树构造不计入演化区间；输入准备另记。每组测五次，冷／热请求交替。原始数据在 [core.json](../../Tools/Benchmarks/Results/core.json)、[metapixel.json](../../Tools/Benchmarks/Results/metapixel.json)、[galaxy.json](../../Tools/Benchmarks/Results/galaxy.json) 与 [scheduler.json](../../Tools/Benchmarks/Results/scheduler.json)。源码和样本哈希在 [source-hashes.json](../../Tools/Benchmarks/Results/source-hashes.json)。

65 份正式记录均完成，失败 0；各区间 `GC.GetAllocatedBytesForCurrentThread()` 增量为 0 B。画笔后的正式人口为 1,049,600，五次均在一次 System Update 内完成。随机序列使用种子 `0x12345678`，每次从相同初态连续计算十六次八代，最终人口均为 6,539，没有回退快照。

另以 Glider 推进 4096 代并核对人口和五个目标坐标；冷／热输出根与位置相同。稳定结构核对人口不变，混合图案冷／热核对完整规范化根，渲染核对白色像素确实产生。

“热缓存”是重放相同快照和相同跨代请求的复用成本，不能解释为后续混沌演化速度。近景与远景的纹理清理仍固定写入 4 MiB；远景离散波动明显。`Apply` 的 CPU 提交另在 JSON 中记录，不代表 GPU 完成时间。未单独做 CPU Profiler 归因，不据此宣称硬件极限或最优配置。

## OTCA 单元与独立结果核对

输入为 Brice Due 的 [OTCA metapixel RLE](https://copy.sh/life/examples/otcametapixel.rle)：64,691 活细胞，2058×2058，B3/S23。该输入是一个宏单元。本轮推进 35,328 代；多宏细胞的完整输入另见下一节。

每次从初态以 32768、2048、512 代三段推进，总计 35,328 代。五次冷缓存为 529.954–782.934 ms，中位数 548.659 ms；交替重放为 146.853–181.794 ms，中位数 162.506 ms。解析单次 49.374 ms，初始树构造约 49.979–62.128 ms，均不包含在演化时间内。

冷请求触发一次增量回收，峰值已占用节点 262,147，完成后 142,326。演化单批最大 5.953 ms，回收单批最大 2.699 ms，说明约 2 ms 调度预算只能在小批次之间生效，不能承诺每帧严格不超时。十个区间均为 0 B，失败 0。

对照使用 [copy/life 原始引擎](https://github.com/copy/life)直接读取相同 RLE 并推进同样代数，不重写参考演化算法。最终人口 64,697，全体坐标按相同 64 位混合函数累计后的和为 `b80862e9e33a47e1`、异或为 `35ed6d6d4e00e5db`，十次与独立参考一致。指纹遍历放在计时与分配区间之外，参考结果见 [metapixel-reference.json](../../Tools/Benchmarks/Results/metapixel-reference.json)。

## 完整 Life-in-Life 输入与正式调度

输入为 Brice Due 的 [metapixel-galaxy.mc](https://copy.sh/life/examples/metapixel-galaxy.mc)，文件注明由 `galaxy.lif` 生成 15×15 个 B3/S23 宏细胞。原文件 122,740 B，通过 [PrepareLifeInLife.py](../../Tools/Benchmarks/PrepareLifeInLife.py) 按 [Golly Macrocell 格式](https://golly.sourceforge.io/Help/formats.html)离线展开为 18,474,689 B 的 RLE。运行时仍只接收既有 RLE 协议，没有增加另一套世界载入路径。

解析后有 7,408,195 个活细胞、556,344 个非空位图叶块，范围 30,720×30,720。原文件、转换结果与位图行内容的 SHA256 见 [galaxy-input.json](../../Tools/Benchmarks/Results/galaxy-input.json)。

五次从初态推进 35,328 代的冷缓存耗时为 4191.344–6372.983 ms，中位数 4733.554 ms。最终人口均为 7,070,723，全体坐标指纹和 `f2c01c6befc06876`、异或 `147baceed955b16a` 均与独立引擎一致。五次交替重放的中位数为 0.055 ms，这只证明相同初态和相同请求能够复用，不能当作下一宏代的速度。

十次推进区间均为 0 B，失败 0。冷请求各触发九轮增量回收，峰值节点 1,854,942。演化单批最大 11.725 ms，回收单批最大 48.086 ms。首次解析约 4894 ms，五次初始建树为 5514–9225 ms；这些成本没有藏进热缓存数字，大型 RLE 导入仍会产生数秒等待。

[MeasureLifeScheduler.cs](../../Tools/Benchmarks/MeasureLifeScheduler.cs) 再以相同输入驱动正式 `LifeSimulationSystem.Update`。准备阶段包含预设建树、盖章、首次回收和 Play 指令处理，随后一次增加 35,328 代待推进量；后续使用零增量时间续跑，直到实际完成。

五次均完成且匹配独立指纹，失败 0、演化区间 0 B。总 CPU 耗时为 4166.786–5833.057 ms，中位数 4774.491 ms，分成 2043–2805 次 System Update。每轮最慢一次 Update 为 2.942–4.765 ms。准备阶段约 5997–6727 ms，不含输入解析。这里的循环没有真实帧等待，也不运行绘制和 UI，因此不是实际 Game 帧率或鼠标延迟测量。

## 空闲帧异常修复

迁移初版在空队列时调用 `DynamicBuffer.RemoveRange(0, 0)`。Entities 1.4.8 先检查起始索引，再处理零数量，所以每次空闲更新均越界。原画笔采样只覆盖有命令的路径，未发现该问题。

已在目标 Editor 复现原异常，改为仅移除本次实际消费的命令前缀。重新编译为 0 错误、0 警告；正式 System 在空队列下更新 360 次、运行状态下更新 120 次，连续画笔得到预期的 33 格，单步得到第 1 代，运行后得到第 121 代，暂停后队列长度为 0。此次通过 CLI 直接检查，未新增 Unity 测试代码。`core.json` 和单 OTCA 采样产生于该修复之前，完整 Galaxy 和正式调度采样产生于修复之后。

## 重现与范围

- [MeasureLife.cs](../../Tools/Benchmarks/MeasureLife.cs) 记录重复、混沌、混合、画笔与树显示，CLI 使用 `--detach eval_file <绝对路径> 600000`，按返回的 jobId 取结果；原始 CLI 响应时间不作性能数据。
- [MeasureLifeInLife.cs](../../Tools/Benchmarks/MeasureLifeInLife.cs) 从 UTF-8 的 `Temp/LifeBenchmarks/request.txt` 读取四行：RLE 绝对路径、重复次数、参考指纹和、参考指纹异或。样本放在忽略的 Temp 目录，不污染用户预设目录。单次推进的计时上限 60 秒，未完成会记录失败。
- `MeasureLifeScheduler.cs` 使用相同四行请求格式，记录正式分帧调度与最终坐标指纹。
- [ReferenceLife.cjs](../../Tools/Benchmarks/ReferenceLife.cjs) 调用未经改写的独立参考引擎。原始文件 [life.js](https://raw.githubusercontent.com/copy/life/master/life.js) 与 [formats.js](https://raw.githubusercontent.com/copy/life/master/formats.js) 分别下载为 `Temp/LifeBenchmarks/life-reference.js`、`formats-reference.js`；SHA256 分别为 `638cabc197b4b36601a08bb24a10f1b68431f3443d59648f742b4a829996da43`、`537d15b7bb3c64c0b3423ad8b610fbdd3b1a5f4bc1d3414728eeddb15f584819`。从工程根执行 `node Tools/Benchmarks/ReferenceLife.cjs <RLE路径>` 得到参考结果。
- Macrocell 转换命令为 `python Tools/Benchmarks/PrepareLifeInLife.py Temp/LifeBenchmarks/Data/metapixel-galaxy.mc Temp/LifeBenchmarks/Data/metapixel-galaxy.rle --source-url https://copy.sh/life/examples/metapixel-galaxy.mc`，保留作者信息与来源。该工具不执行演化，也不加入运行时程序集。
- 已编译工作区：Unity CLI 返回 0 错误、0 警告。未新增 Unity 测试代码。
- 尚未测量完整 Game 帧、实际鼠标到显示的延迟、UI Toolkit／结构库动态预览的分配与耗时，也未完成所有内置周期和端到端交互验收；由用户实际验收。
